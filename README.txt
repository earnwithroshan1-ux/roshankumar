ROSHAN KUMAR WEBSITE
====================

1. Zip ko extract karo.
2. index.html par double-click karo, website browser me khul jayegi (internet chahiye, fonts ke liye).

Kya badalna hai
---------------
- WhatsApp link: index.html ko Notepad ya VS Code me kholo, "YOUR-INVITE-CODE" search karo.
  Script ke andar WA_LINK wali line me apna asli invite link daalo (sirf ek jagah).
- Photo: About section me "RK" wala block apni photo se badlo.
- Naam aur text: seedha index.html me edit karo.

Online daalne ke liye (free): Netlify Drop, GitHub Pages ya Vercel par index.html upload karo.
